## Ограничения приёмки

Реальные Telegram/VK-чаты не использовались: нужны выделенные токены и chat/peer
IDs; integration-тест использует `MemoryAdapter`. Реальная ASR-модель не была
предоставлена — аудио проверено только по протоколу с заглушкой. Источники
не записываются автоматически в RAG и не меняют правила доменных навыков.

Общая двухсекундная очередь действует внутри одного процесса/event loop;
для нескольких экземпляров бота нужна распределённая координация.
Полная публикационная приёмка остаётся открытой до восстановления хаба,
проверок в выделенных чатах и прохождения полных пользовательских сценариев.
